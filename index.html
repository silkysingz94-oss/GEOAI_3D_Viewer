Methodology
Administrative filtering is attribute-based using the EA boundary attributes. Thematic features are spatially filtered against the selected EA geometry using Turf.js. This is a feature-intersection filter, not a geometric clipping operation.

Data sources
Census EA GeoJSON: configured GitHub repository. Administrative boundaries: ArcGIS Feature Service. Thematic features: OpenStreetMap / Overpass API. Basemaps: CARTO, Esri and OpenStreetMap.
