Methodology and data notes

Data are requested from the configured public services when selected. OSM-derived features represent mapped OpenStreetMap content and may be incomplete. Administrative boundary availability depends on the ArcGIS service. Census EA data are loaded from the configured GitHub repository.

3D building display uses mapped building footprints and height attributes where available. Missing heights receive a visual default and are not surveyed heights.

Sources: OpenStreetMap contributors; ArcGIS Feature Service; Urban-Planning-Intelligence GitHub repository.
