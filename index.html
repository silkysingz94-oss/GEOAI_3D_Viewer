Methodology and interpretation

EA aggregation: Statistics are calculated from the selected EA features. Population density is total population divided by total area, not the average of EA-level densities.

3D extrusion: EA polygons are extruded using a square-root-scaled thematic value to improve visual contrast. Extrusion is not a measured physical height.

GPS matching: Imported and captured GPS coordinates are tested against loaded EA polygon geometry. Points not matched to a loaded EA are classified as outside/unmatched.

Area: The dashboard uses recognised area attributes where available. If no usable area attribute is available, it calculates an approximate geodesic polygon area.
