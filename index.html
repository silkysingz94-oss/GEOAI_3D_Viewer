Methodology and data notes
EA statistics are calculated from the attributes available in the loaded GeoJSON. Population density is calculated as population divided by EA area in square kilometres. 3D extrusion height is a visual scaling of the selected indicator and is not a measured building height. Missing or zero values are not treated as observed values. The map uses a fixed Esri satellite imagery layer with reference labels.
