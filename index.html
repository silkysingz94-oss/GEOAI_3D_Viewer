Data provenance

Census, built-up, education, road and settlement datasets are fetched from the GEOAI_3D_Viewer GitHub repository. Additional mapped features are requested from OpenStreetMap using Overpass API.

OpenStreetMap content is community-mapped and may be incomplete. It should not be interpreted as a complete official GBoS inventory.

Building heights use mapped OSM attributes where available. Missing heights receive a visual default and are not surveyed heights.

Sources: GitHub GEOAI_3D_Viewer; OpenStreetMap contributors; CARTO; Esri.
